# Релиз

Пакет скиллов Мэтта Покока для ИИ-агентов.

## GitHub

Название релиза: `like_mattpocock: skills workflow for AI agents`

Текст:

Подготовлен набор из пяти адаптированных скиллов Мэтта Покока и оркестратора
`ai-coder` для ИИ-агентов.

Маршрут: вопросы по задаче, спецификация, тикеты, реализация и ревью.

Важные решения остаются за человеком: ответы на вопросы, подтверждение
спецификации и подтверждение тикетов.

## Threads

ИИ-агенту мало дать большую задачу одним сообщением.

В этом наборе он сначала задает вопросы по проекту, затем оформляет
спецификацию, нарезает тикеты, реализует их по одному и запускает ревью.

Внутри пять скиллов Мэтта Покока и `ai-coder`, который связывает их в один
